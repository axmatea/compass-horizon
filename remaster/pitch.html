REMASTER · LONG HORIZON AGENTS HACKATHON

The AI company manager that sleeps on it

It ran a 10-person startup for a full quarter and never lost the plot — because it forgets on purpose, tests its own forgetting, and can always restore the exact fact it needs.

THE PROBLEM

Long-horizon agents die from memory. Keep everything → the model drowns in its own history. Summarize → a generic model guesses today what will matter later, deletes the wrong thing forever, and nobody ever checks. The facts that matter most are tiny and old: "Sarah is off in week 9 — wedding."

HOW IT WORKS — THREE LAYERS + THE TRIPLE DELAY

1

The Strategist owns the quarter

Thinks in months, like a CEO. Sets each week's plan and knows what will matter later.

2

Every night, a disposable copy of the Strategist cleans the memory

The fork reviews the day and decides what the Manager keeps, folds, promotes, or archives — forgetting by intent, because only the one who knows the plan knows what's safe to forget. Then the copy is destroyed.

3

The Manager runs the company on ~400 tokens

Thinks in days, like a COO: assigns work, unblocks people, reacts when someone says "our vendor slipped" — on a tiny, curated working memory.

✓

The triple delay proves the memory is safe

Three copies of the Manager replay the same decision on older memory — 1 day behind, 1 week behind, never cleaned. All agree → forgetting was safe. They differ → the cleanup deleted something that mattered, and the exact fact is restored from the append-only archive.

Strategist
= the CEO

Night cleaner
= the CEO's fork, at 2am

"Knowing the plan — what should the COO remember tomorrow?" Sorts memory, then vanishes.

Manager
= the COO

Runs the day. Talks to the team. Reshuffles the week when reality changes.

The one-liner: "Most agents forget by accident. Ours forgets on purpose — and proves it. Working context stays ~400 tokens for an entire quarter, on a 2.6-billion-parameter model. The architecture does the work, not model size."

REMASTER · THE STACK

Four tools, four load-bearing jobs

Remove any of them and the system breaks — none of this is decoration.

Liquid
LFM-2.5 · 2.6B
Every brain in the system. The strategist, the manager, the night cleaner, the three delayed copies, the judge — six agent roles, one tiny model, called via API, $0 total. Small enough to run on a phone.
Remove it → nothing thinks. The whole point: long horizons need architecture, not giant models.
Tinybird
Rawtree
The memory itself. Every event, decision, and standup is appended forever — nothing is ever deleted. The manager literally runs SQL over its own past to remember, and when forgetting breaks something, the exact fact is recovered from here.
Remove it → forgetting becomes permanent, and the whole "reversible memory" thesis collapses.
Nimble
The outside world. When a teammate reports "our vendor slipped," the agent researches alternatives on the live web before replanning. Market signals feed the strategist's weekly plans.
Remove it → the agent plans blind, in a simulation bubble.
Black Forest Labs
FLUX 3
The Monday briefing. The strategist's weekly plan becomes a 10-second text-to-video briefing with voice — the team's Monday morning stand-up video, generated from the real state of the company.
Remove it → the humans lose their window into what the agent decided.
Live demo: the week board runs in real time — pick any teammate, tell the manager "our provider got delayed, we'll only have it tomorrow," and watch it query its Rawtree memory, check the web through Nimble, answer you, and reshuffle the week so nobody idles. Every thought on screen is Liquid.
